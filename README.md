# Sentinel

A simple Telegram bot that captures a photo from a webcam and sends it.

## Requirements

- Webcam connected to the computer
- Telegram Bot Token (create a file ~tok.py and paste it here as a tok variable)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/ILOSman/Sentinel.git
cd Sentinel
```

2. Install the dependencies:
```
pip install aiogram opencv-python
```
3. RUN
```
python main.py
```
